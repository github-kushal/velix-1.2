# VELIX (Virtual Enhanced Learning Intelligent Executor)

VELIX is a modular AI assistant inspired by JARVIS from Iron Man. It combines local AI models, natural language processing, memory systems, and automation capabilities into a single intelligent assistant.

---

## Features

* Voice Interaction
* Wake Word Detection
* Local LLM Integration (Ollama)
* Short-Term Memory
* Long-Term Memory
* Context Management
* Smart Memory Detection
* Application Automation
* Web Automation
* File Management
* Extensible Skill System
* Modular Architecture
